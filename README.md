[Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for the
Debian Almquist Shell 0.5.13.5.

## Installation

```sh
npm install tree-sitter-dash
```

## Development

```sh
npm install
npm run build
npm test
```
